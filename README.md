# Data Analyst Portfolio – Ready to Customize

A clean, modern, dark-themed single-page portfolio designed for Data Analysts.

## How to use

1. Open `index.html` in any browser to preview.
2. Edit the file with any text editor (VS Code, Notepad, etc.).
3. Replace all placeholder content with your real information:

### What to change

| Section       | What to edit                                      |
|---------------|---------------------------------------------------|
| Hero          | Your name, one-line value proposition             |
| About         | Your real experience, impact numbers, story       |
| Projects      | 3–5 real projects (title, impact, tools, links)   |
| Skills        | Your actual tools and strengths                   |
| Experience    | Real jobs / education                             |
| Contact       | Your email, LinkedIn, GitHub                      |

### Quick find & replace tips
- Search for `Alex Rivera` → replace with your name
- Search for `alex.rivera@email.com` → your email
- Update all project links (`href="#"`) to real GitHub / Tableau Public / blog links
- Update the impact metrics (↑ 18%, ↓ 12%, etc.) with real results

## Hosting (free options)

- **GitHub Pages**: Push this folder to a GitHub repo → Settings → Pages → Deploy
- **Netlify Drop**: Drag the folder to [netlify.com/drop](https://app.netlify.com/drop)
- **Vercel**: Import the repo or drag & drop

## Customization ideas

- Change the accent color in the `:root` CSS variables (`--accent`)
- Add real project screenshots by replacing the emoji placeholders
- Add a resume download button linking to a PDF
